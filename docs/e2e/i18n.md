# i18n E2E

Playwright suite that validates dashboard translations in two layers:

1. **Static** (`i18n-static.spec.ts`) — no browser: locale JSON parity (+ source key scan when dashboard `src/` is present).
2. **UI** (`i18n.spec.ts`) — drives the running webapp and asserts every visible `[data-i18n-key]` against locale JSON.

Run Static before relying on UI results (`--project=i18n` includes both; `i18n-static` sorts first).

## Run

```bash
npx playwright test --project=i18n
npx playwright test --project=i18n --grep @i18n
npx playwright test --project=i18n tests/specs/i18n-static.spec.ts
```

Requires `APP_URL` and login credentials in `.env` for UI cases (same as farm/overview).

**Session (UI):** login once per worker (`authenticatedDashboardSession`), serial run.  
**Order (UI):** TC01 → TC03 → TC05 → TC06 → TC08 → … → TC12, then **TC04** and **TC07** last (logout / re-login).

Optional: `DASHBOARD_ROOT=/path/to/xahwm-dashboard` if the dashboard repo is not a sibling of this e2e repo.

## Contract (dashboard)

| Rule | Detail |
|------|--------|
| Mark copy | Every visible `t()` / `Trans` / `translateKey` string exposes `data-i18n-key` on the same element |
| Discover | UI tests scrape `[data-i18n-key]:visible` — **no hardcoded key list** for those asserts |
| New string | Add `data-i18n-key` on web → re-run suite; **no e2e code change** |
| Placeholders | `Total {{total}} items` → match `Total \d+ items` (value not asserted) |
| Not marked | API data, chart counts, moment weekdays, `language-option-*` |

See `xahwm-dashboard/docs/e2e/README.md`.

## Cases

### Static

| ID | Title | Note |
|----|-------|------|
| TC-STATIC-01 | locale JSON files share the same keys as en | All `src/locales/lang/*.json` |
| TC-STATIC-02 | source `t()` / `i18nKey` literals exist in en.json | Skipped when CI sparse-checkout has no `src/views` |

### UI

| ID | English title | Note |
|----|---------------|------|
| TC01 | switching language updates marked farm labels from locale JSON | Every menu language; scrape farm `[data-i18n-key]` |
| TC02 | reload keeps selected language | F5 keeps locale + marked labels |
| TC03 | side nav labels follow selected language | Room view marked nodes (incl. nav) |
| TC04 | sign-in screen follows persisted language after logout | Auth marked nodes + email placeholder |
| TC05 | overview page labels follow selected language | Room/overview marked nodes |
| TC06 | pagination total matches interpolated translation pattern | `data-i18n-key` on `pagination-total` |
| TC07 | language persists after logout and login | Dashboard marked nodes after re-login |
| TC08 | switching language on animal page updates marked labels | Animal Management scrape |
| TC09 | chart week labels and weather weekdays follow locale | Chart / moment (not `data-i18n-key`) |
| TC10 | second tab sees same language after reload | Shared context / redux-persist |
| TC11 | UI does not show raw i18n keys | No `nav.` / `container.` / `global.` paths |
| TC12 | tags chart tooltip still shows week date range after language switch | Tooltip has `DD/MM/YYYY` |

- `pagination-total`, `room-tags-title`, `animal-mgt-barn-details-title`, `login-button`
- Any other visible `[data-i18n-key]` on navigated routes
