# i18n E2E

Playwright suite that validates dashboard translations in two layers:

1. **Static** (`i18n-static.spec.ts`) — no browser: locale JSON parity (+ source key scan when dashboard `src/` is present).
2. **UI** (`i18n.spec.ts`) — drives the running webapp and asserts every visible `[data-i18n-key]` against locale JSON.

Run Static before relying on UI results (`--project=i18n` includes both; `i18n-static` sorts first).

## Run

```bash
npx playwright test --project=i18n
npx playwright test --project=i18n --grep @i18n
npx playwright test --project=i18n tests/specs/i18n-static.spec.ts
```

Requires `APP_URL` and login credentials in `.env` for UI cases (same as farm/overview).

**Session (UI):** login once per worker (`authenticatedDashboardSession`), serial run.  
**Order:** **TC01** / **TC02** (static, no browser) first, then UI TC03 → TC05 → TC07 → TC08 → TC10 → … → TC14, then **TC06** and **TC09** last (logout / re-login).

Optional: `DASHBOARD_ROOT=/path/to/xahwm-dashboard` if the dashboard repo is not a sibling of this e2e repo.

## Contract (dashboard)

| Rule | Detail |
|------|--------|
| Mark copy | Every visible `t()` / `Trans` / `translateKey` string exposes `data-i18n-key` on the same element |
| Discover | UI tests scrape `[data-i18n-key]:visible` — **no hardcoded key list** for those asserts |
| New string | Add `data-i18n-key` on web → re-run suite; **no e2e code change** |
| Placeholders | `Total {{total}} items` → match `Total \d+ items` (value not asserted) |
| Not marked | API data, chart counts, moment weekdays, `language-option-*` |

See `xahwm-dashboard/docs/e2e/README.md`.

## Cases

| ID | English title | Note |
|----|---------------|------|
| TC01 | locale JSON files share the same keys as en | Static — all `src/locales/lang/*.json` |
| TC02 | source `t()` / `i18nKey` literals exist in en.json | Static — skipped when CI sparse-checkout has no `src/views` |
| TC03 | switching language updates marked farm labels from locale JSON | UI — every menu language; scrape farm `[data-i18n-key]` |
| TC04 | reload keeps selected language | UI — F5 keeps locale + marked labels |
| TC05 | side nav labels follow selected language | UI — room view marked nodes (incl. nav) |
| TC06 | sign-in screen follows persisted language after logout | UI — auth marked nodes + email placeholder |
| TC07 | overview page labels follow selected language | UI — room/overview marked nodes |
| TC08 | pagination total matches interpolated translation pattern | UI — `data-i18n-key` on `pagination-total` |
| TC09 | language persists after logout and login | UI — dashboard marked nodes after re-login |
| TC10 | switching language on animal page updates marked labels | UI — Animal Management scrape |
| TC11 | chart week labels and weather weekdays follow locale | UI — chart / moment (not `data-i18n-key`) |
| TC12 | second tab sees same language after reload | UI — shared context / redux-persist |
| TC13 | UI does not show raw i18n keys | UI — no `nav.` / `container.` / `global.` paths |
| TC14 | tags chart tooltip still shows week date range after language switch | UI — tooltip has `DD/MM/YYYY` |

## Web hooks used

- `language-selector`, `language-selector-value`, `language-option-{locale}`

- `nav-item-{key}` (+ `data-i18n-key`)
- `farm-tags-title`, `farm-tags-inventory`, `farm-tags-chart`
- `farm-weather-panel`, `farm-weather-weekday`, `farm-weather-empty`
- `pagination-total`, `room-tags-title`, `animal-mgt-barn-details-title`, `login-button`
- Any other visible `[data-i18n-key]` on navigated routes
