# i18n E2E

Playwright suite that drives the running webapp and compares visible UI text to locale JSON files in `xahwm-dashboard`.

## Run

```bash
npx playwright test --project=i18n
npx playwright test --project=i18n --grep @i18n
```

Requires `APP_URL` and login credentials in `.env` (same as farm/overview).

**Session:** login once per worker (`authenticatedDashboardSession`), serial run.  
**Order:** TC01 → TC03 → TC05 → TC06 → TC08 → … → TC12, then **TC04** and **TC07** last (logout / re-login).

Optional: `DASHBOARD_ROOT=/path/to/xahwm-dashboard` if the dashboard repo is not a sibling of this e2e repo.

## CI (workflow_dispatch)

**Actions** → **E2E Playwright**, hoặc Slack:

| Slash | Path | Suite |
|-------|------|--------|
| `/xlm-test-overview` | `/overview` | **Languages** (shared; `project=i18n`) |
| `/xlm-test` | `/all` | farm + overview panels |
| `/xlm-test-farm` | `/farm` | farm |

`dashboard_ref=auto` maps from `APP_URL` when languages run. See [CI.md](../CI.md).

## Cases (easy → hard)

| ID | English title | Note |
|----|---------------|------|
| TC01 | switching language updates farm labels from locale JSON | Every menu language; farm labels match that JSON. |
| TC02 | reload keeps selected language | F5 keeps locale + labels. |
| TC03 | side nav labels follow selected language | Header HorizontalNav (`nav.*`) on room view (Simple layout). |
| TC04 | sign-in screen follows persisted language after logout | Auth screen uses persisted locale. |
| TC05 | overview page labels follow selected language | Room tags title on `/overview`. |
| TC06 | pagination total uses interpolated translation | `{{total}}` on `pagination-total` after opening `/animal`. |
| TC07 | language persists after logout and login | Dashboard still correct after re-login. |
| TC08 | switching language on animal or alerts page updates that page | Animal Management barn title on `/animal`. |
| TC09 | chart week labels and weather weekdays follow locale | Chart x-axis + moment weekdays. |
| TC10 | second tab sees same language after reload | Shared context / redux-persist. |
| TC11 | UI does not show raw i18n keys | No `nav.` / `container.` / `global.` paths. |
| TC12 | tags chart tooltip still shows week date range after language switch | Tooltip has `DD/MM/YYYY` (`formatDate`). |
